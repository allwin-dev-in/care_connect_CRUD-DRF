# Care Connect - Healthcare Booking & Management System

Care Connect is a robust backend web application built with **Django** and **Django REST Framework (DRF)** designed to streamline healthcare facility operations, patient bookings, and staff administration.

## Features
* **Patient Booking System**: Manage appointments and bookings seamlessly with versioned endpoints (`booking` & `booking_v2`).
* **Staff Management**: Comprehensive tracking and administration of medical and administrative staff members (`staff` & `staff_v2`).
* **RESTful APIs**: Fully documented endpoints via HTTP configuration for frontend integration.
* **Database Management**: Integrated with SQLite and migrations for robust data consistency.

## Tech Stack
* **Python / Django / Django REST Framework**
* **Database**: SQLite
* **API Testing**: APIDOC.http
